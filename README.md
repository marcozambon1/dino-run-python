# Jogo do Dino

Este é um projeto desenvolvido para compor o portfólio da disciplina de **Desenvolvimento de Jogos Digitais**. 

Trata-se de um jogo desenvolvido em Python (comumente utilizando a biblioteca Pygame), focado em aplicar na prática os fundamentos de design e programação de games.

## 🎮 Sobre o Projeto

O objetivo principal deste desenvolvimento foi consolidar os conhecimentos adquiridos na disciplina, abordando conceitos essenciais como:
*   Game Loop e controle de FPS
*   Renderização de gráficos (sprites) e animações
*   Detecção de colisões
*   Captura de eventos e inputs do jogador
*   Lógica de pontuação e condições de Game Over

## 🚀 Tecnologias Utilizadas

*   **Linguagem:** Python 3
*   **Biblioteca:** Pygame (ou a biblioteca utilizada no projeto)

## 🛠️ Como Executar o Jogo Localmente

Siga as instruções abaixo para rodar o jogo em sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/marcozambon1/dino-run-python.git
   cd dino_jogo
   ```

2. **Crie e ative um ambiente virtual (Recomendado):**
   ```bash
   python3 -m venv .venv
   
   # Para ativar no Linux/macOS:
   source .venv/bin/activate
   
   # Para ativar no Windows:
   .venv\Scripts\activate
   ```

3. **Instale as dependências:**
   Caso possua um arquivo `requirements.txt`, execute:
   ```bash
   pip install -r requirements.txt
   ```
   Se não, instale as bibliotecas necessárias, por exemplo:
   ```bash
   pip install pygame
   ```

4. **Inicie o jogo:**
   ```bash
   python dino_jogo.py
   ```
   *(Substitua `main.py` pelo nome do seu arquivo principal, caso seja diferente).*
